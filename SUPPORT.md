## `01 // BEFORE ASKING`

Before requesting help, please check:

1. The project's README.
2. The project's documentation.
3. Existing GitHub Issues.
4. Existing Discussions, if available.
5. The project's release notes or changelog.

Your question may already have an answer.

---

## `02 // WHERE TO ASK`

Different problems belong in different channels.

| Problem | Where to go |
|---|---|
| 🐛 Bug | GitHub Issue |
| 💡 Feature idea | GitHub Issue / Discussion |
| 🔐 Security vulnerability | `SECURITY.md` |
| 💬 General question | GitHub Discussions, if enabled |
| 🧑‍💻 Contribution | `CONTRIBUTING.md` |
| 🚨 Community problem | `CODE_OF_CONDUCT.md` |
| 📖 Documentation problem | GitHub Issue |
| 🎮 Game feedback | Project-specific channel |
| 🧪 Experimental project | Project repository |

Always check the individual repository first because
different SDT projects may use different support channels.
