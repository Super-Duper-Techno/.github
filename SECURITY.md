## `01 // SECURITY AT SDT`

Super Duper Techno takes the security of its projects seriously.

Our projects may involve:

- Software
- Games
- Networking
- AI systems
- Operating systems
- Hardware concepts
- Communication systems
- Experimental technologies

Security issues can affect users, developers, infrastructure,
or other projects connected to the SDT network.

If you discover a vulnerability, please report it responsibly.

---

## `02 // DO NOT DISCLOSE PUBLICLY`

Please **do not create a public GitHub issue** for a security
vulnerability.

Do not publicly post:

- Passwords
- API keys
- Access tokens
- Private keys
- Authentication credentials
- Database credentials
- Personal information
- Exploit code for an undisclosed vulnerability
- Internal infrastructure information

Public disclosure before a fix is available may put users and
contributors at unnecessary risk.

---
