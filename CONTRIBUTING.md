## `01 // BEFORE YOU ENTER`

Super Duper Techno is an independent, founder-led studio.

We build games, software, networks, hardware concepts, AI systems,
original worlds, entertainment, and experimental technology.

Some projects are serious.

Some are weird.

Some are both.

That's intentional.

Before contributing, please understand that every repository has its
own purpose, technology stack, development stage, and rules.

**Read the repository's README before touching the code.**

---

## `02 // WHAT WE LIKE`

We value:

- Creativity over imitation.
- Useful ideas over unnecessary complexity.
- Fun over corporate stiffness.
- Original work over trend chasing.
- Experimentation over fear of failure.
- Clear communication over unnecessary meetings.
- Small, understandable solutions over giant complicated ones.
- People who actually build things.

You don't need to be an expert to contribute.

You do need to be willing to learn.

## `05 // BEFORE OPENING AN ISSUE`

Before creating an issue:

1. Search existing issues.
2. Check the repository README.
3. Make sure the problem is reproducible when possible.
4. Include enough information for someone else to understand the issue.
5. Don't use issues for personal support unless the repository says
   otherwise.

A good bug report should answer:

```text
WHAT HAPPENED?
WHAT DID YOU EXPECT?
HOW CAN WE REPRODUCE IT?
WHAT ENVIRONMENT ARE YOU USING?
ANY RELEVANT LOGS / SCREENSHOTS?
