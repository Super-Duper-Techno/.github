# `// WHO ARE WE?`

**Super Duper Techno** is an independent, founder-led technology and creative studio building across **games, software, hardware, networks, AI, media, entertainment, research, and original storytelling.**

SDT didn't begin in a boardroom.

It started in **2016 as a YouTube channel talking about other people's worlds.**

Eventually, talking about worlds wasn't enough.

So we started building our own.

One idea became another.

Then another.

And eventually:

**eight divisions. one system.**

The original rule never changed:

> **Creativity and fun over standard edition.**

We don't build something because that's how it's normally done.

We build it because **we think it should exist.**
